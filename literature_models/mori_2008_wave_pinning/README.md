# Mori 2008 wave-pinning model

The active implementation is `../../migration1d/src/migration1d/mori.py`, with
the endpoint and reversal experiments in the corresponding campaign modules
and JSON configs. This bundle retains the earlier scientific report. No second
copy of the solver is kept here.

- `src/`: intentionally empty; canonical source is in `migration1d`.
- `scripts/`: intentionally empty; use the generic migration runner.
- `params-or-config/`: canonical configs are under `migration1d/configs/`.
- `results/`: generated output belongs under `migration1d/results/`.
