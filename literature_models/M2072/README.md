# M2072 — retired 17 October 2026

The user retired this exploratory project to recover storage. Its simulation campaigns, optimization infrastructure, reports, trajectories, masks, checkpoints, binaries, and fitted emulators were deliberately removed. The compact [retirement record](retirement_20261017/) preserves the project’s purpose, selected models, parameters and scalar summaries. This is a historical record, not a runnable reconstruction of every campaign.

M2072 explored a two-dimensional cellular Potts model as a bridge from polarity mechanisms to cell migration. Rac-dependent protrusive drive coupled cell shape to a perimeter-derived tension signal, Rac/Rho chemistry and conserved effective bound-MCA transport. The intended scientific question was whether plausible mechanochemical cells could explain migration changes under WGD-associated enlargement, and whether long-range coordination changed those responses. A qualified final ensemble and a general WGD-persistence conclusion were not established by this record.

Early work fitted biochemical modules and a perimeter-response emulator, selected six mechanically separated original V1–V6 pairings, and then explored coupled refinements. Original and jointly refined V1–V6 use the same labels with different parameters. The authoritative original six remain in [the parameter panel](retirement_20261017/parameters/original_V1_V6_panel.json), with [their resting-perimeter references](retirement_20261017/parameters/original_V1_V6_resting_reference.json).

The final workflow used 32 fixed mechanical anchors, circular-PDE biochemical initialization and native CPM refinement against literature-based movement targets plus relaxed deBelly response criteria. The final stopped-campaign report reconciled 14,965 screens, 991 validations and 226 size results. Twenty-seven anchors had a lowest-loss validated leader; these remain search-selected candidates rather than a final independent qualification. All 36 manually scheduled missing size runs completed. [The scalar campaign record](retirement_20261017/summary/campaign_summary.json) supersedes stale dispatcher files that had still said “running.”

The surviving model examples are [mechanics-only Morpheus XML](retirement_20261017/models/mechanics_only.xml) and [a coupled model XML](retirement_20261017/models/coupled_anchor05_warmup.xml) from the final anchor-05 leader. Both contain their model definitions without external model-file dependencies. The coupled example is the original first-seed warmup configuration, not a six-hour simulation checkpoint or a full assay. Its [complete candidate dictionary](retirement_20261017/parameters/coupled_anchor05_candidate.json) includes the resting calibration. Running either XML requires a compatible Morpheus installation; the historical binary itself was removed.

[Compact leader parameters and movement summaries](retirement_20261017/parameters/current_leader_parameters.json) retain one candidate per represented anchor. [Size diagnostics](retirement_20261017/summary/size_diagnostics.csv) contain finite-track MSD exponents at 0.5×, 1× and 2× volume when available. The size convention scaled geometry by the cube root of volume, with corresponding area-strength adjustment; it was a size-only diagnostic without gene-dosage changes or size-specific fitting. These outputs are conditional model predictions. Literature-derived OU compatibility targets are not independent migration data or empirical confidence intervals, and different target-family objective values are not likelihoods.

The [historical workflow description](retirement_20261017/history/anchor_workflow_README.md) documents protocols and limitations. Its old links describe paths that were intentionally removed. The [retained-file manifest](retirement_20261017/RETENTION_MANIFEST.json) records source paths, hashes and the purposes of copied or reduced records. Historical manifests refer to deleted files and are not a promise that those files survive. The [cleanup status](retirement_20261017/cleanup_status.json) records measured storage and the completed deletion scope.

Do not restart or reconstruct M2072 campaigns as incidental repository upkeep. Any renewed M2072 work requires a new user instruction and a new plan; active polarity models elsewhere in the repository were outside this cleanup.
