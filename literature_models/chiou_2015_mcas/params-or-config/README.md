# Chiou model resource

`initial_state_1D.mat` is the published initial state distributed with the
Chiou supplementary MATLAB implementation. The native reproduction and WGD
adapter require its `u` and `v` arrays; it is tracked here because `dev/` is an
ignored development/reference directory and must not contain runtime
dependencies.
