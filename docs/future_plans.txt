Complete the model landscape and standardize the scaling experiment. Finish the literature review of relevant intracellular/migration/polarity/resource models, identify which are reproducible enough to implement, and apply a common hierarchy of size perturbations wherever possible: fixed abundance, fixed concentration, empirical abundance scaling, geometrically similar enlargement, and empirically measured WGD geometry. This makes the models comparable rather than a succession of bespoke experiments. The existing polarity set already shows why this matters: different models range from essentially size-robust to quite strongly size-sensitive.
Replace abstract 1×/2× cells with experimentally measured WGD cells. The planned 3D-volume/2D-calibration work becomes foundational infrastructure for the entire sandbox rather than just a metabolic-normalization experiment. Measure volume, projected area, effective height, nuclear dimensions, shape and confluence effects across the WGD panel, then define a small library of representative geometries corresponding to the actual size distributions. Once that exists, every model can ask both “what happens at exactly 2× volume?” and the much stronger question “what does this model predict for the measured WGD size shift in MCF10A/SNU668/etc.?”
Build an empirical molecular-scaling layer. For important model species or classes, begin recording how relevant cellular quantities actually scale with size: total abundance, concentration, membrane-associated fraction, organelle abundance, perhaps transporter abundance. This is especially important because the sandbox has already demonstrated that geometry alone versus geometry plus dilution/partitioning can give completely different answers. Use the sandbox to generate candidate phenotypes for Aim 1 and mechanistic experiments for Aims 2–3. Aim 1 is fundamentally a discovery/allometry aim. The sandbox can tell you which measurable traits should respond strongly enough to size to be worth putting into the phenotyping panel. For metabolism, the current oxygen and transport models can help identify regimes where enlargement should become consequential—especially near resource limitation rather than under abundance. For migration, the polarity models can nominate front stability, stimulus threshold, competing polarity domains and GTPase localization as mechanistic measurements accompanying trajectory analysis. That turns modeling into experimental prioritization rather than post-hoc interpretation.
Make model → prediction → experiment → model a formal workflow. For each serious candidate mechanism, require the same chain: published model reproduced → size perturbation applied → quantitative prediction stated → corresponding observable defined → experiment performed → model accepted/rejected/refined. The migration/polarity project would be the first full demonstration. For example, Eroumé predicts increased persistence of competing Cdc42 domains in enlarged cells; Holmes predicts reduced polarity sensitivity through membrane accessibility; imaging can then directly ask whether either phenomenon actually accompanies the WGD size shift. This is exactly the experimental–computational transition the Instructor/K25 strategy is supposed to demonstrate.
Add a cross-model synthesis layer rather than continually expanding the catalogue. Eventually the most useful sandbox output would be a matrix like process × mechanism × scaling assumption × predicted size sensitivity × experimental observable × empirical status. That lets you identify recurring principles—for example surface/volume mismatch, diffusion-distance penalties, membrane/bulk partitioning, network pattern-selection thresholds, or transport-network path-length effects—and distinguish them from one-model curiosities. It would also give the K25 a very clean conceptual figure: physical enlargement → specific scaling mismatch → model-predicted phenotype → targeted measurement.
