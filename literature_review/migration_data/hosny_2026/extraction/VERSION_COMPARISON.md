The journal is designated a free article by PubMed. Elsevier API metadata declares full open access under CC BY-NC-ND 4.0. However, ScienceDirect HTML and Cell PDF requests returned HTTP 403 and the accessible Elsevier API response contains only `coredata`, without article body, figures or supplements. This is a technical access failure in this session, not evidence of a paywall or absence of supplements. See `../access/extraction_access_attempts.json`, `../access/hosny_final_access_retry.xml`, and `../access/hosny_final_pubmed.html`.

The preprint PDF and Figure 2, 3, 5–10 JPEG downloads succeeded with a browser User-Agent; figures also required the `?download=true` locator. All quantitative outputs retain their preprint identity and hashes. The final-vs-preprint numerical comparison is unresolved; do not label these values as verified final-publication data. No authors were contacted.
