# WGD manuscript vision

Oct 23, 2026 · Richard Beck

Author-owned reference for the manuscript's aims. Agents may read it; agents
do not edit it.

- Cell enlargement changes how polarity is organized and how an established
  polarity is replaced.
- These changes suggest a physical basis for the greater migration persistence
  of WGD-associated enlarged cells.
- Existing published migration data support this hypothesis.
- Model analysis identifies distinct mechanisms through which length could
  cause increased persistence; mechanistic explanations should lead directly to
  specific cellular measurements that could support the corresponding
  behaviour (even if not uniquely confirm it).
- Follow-up experiments aim to confirm and *expand upon* existing literature
  WGD migration data. If model analysis guided single cell migration follow-up
  experiments are strongly suggestive and motivate further targeted
  experiments, this would be considered a good result.
- Model analyses can have multiple roles. Each result should be presented in a
  way that understands and maximizes its role(s):
  1. pedagogical — results are presented that are already established in the
     migration literature;
  2. novel — substantive, truly novel insights about the effects of size on
     cell polarity;
  3. hypothesis generating / experimental — generating useful experimental
     protocols and observation signatures that could be tested.
