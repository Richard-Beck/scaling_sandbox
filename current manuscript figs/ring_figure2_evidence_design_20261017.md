# Expanded Figure 2: existing evidence and proposed comparisons

This is a bounded design/evidence map, not a new figure variant. No new integration, cue protocol or native state was generated. **Updated dependency: the new Figure 1C will use a common active-incumbent deactivation/recovery assay, whose definition is under review. The new main Figure 2C must use that exact same assay. Existing inactive-withdrawal K₀/K₁₀ coefficients below are legacy support and cannot fill the new main C.** Figure 1 remains the established linear all-five comparison; the deBelly ring development remains a separate sidecar. The proposed sequence is: establish the ring counterpart of incumbent organization and function, show size/location maps of the functional readouts, illustrate three spatial outcomes, then examine the resulting global activity vector in those retained histories.

## 1. The baseline comparison should use a mirror extension

A boundary incumbent in a no-flux interval of length $L$ has a natural symmetric counterpart on a periodic ring of circumference $C=2L$. Reflect every native chemical field, not just the primary field:

\[
q_{\mathrm{ring}}(s)=q_{\mathrm{linear}}(|s|),
\qquad -L\leq s<L,\qquad C=2L.
\tag{1}
\]

For a symmetric basal state, concentration and local reaction coefficients agree; the full ring core has twice the interval core's width and amount. The ratio of net repair rate to damage is unchanged because both integrals double. The reflection argument applies to the autonomous native reaction–diffusion equations and a reflected disturbance. It is not a biological calibration of circumference to the original cell-length coordinate. Comparing the same numerical $C=L$ instead changes the material available to a whole incumbent versus a boundary half-incumbent.

**Thirteen exact size matches already exist**, with no interpolation or replacement of stored states: WP/Goryachev $L=5,15,25,35$ against $C=10,30,50,70$; Holmes $L=10,15,20,25,30$ against $C=20,30,40,50,60$. The [matched native measurements and checkpoint hashes](../polarity1d/manuscript/figures/length_mechanisms_20261008/dev/chemical_ring_functional_20261017/supporting/data/ring_functional_ring_linear_mirror_comparison.csv) retain absolute values, cell counts and mesh spacings. The compact common profile comparison can use **L15/C30 and L25/C50 in all three models**. Overlay the actual native samples after reflection and a coordinate shift, without using an interpolated profile as a simulation input.

These legacy repair comparisons use the three available common sizes L15/25/35 for WP/Goryachev. The ring grid is h=0.05; the retained linear grid uses 201 cells, so its spacing varies with L. The small discrepancies demonstrate close agreement of these retained basals and readouts, not a formal continuum-convergence result. Preparation cues also differ; these are independently prepared states on the same basal branch, not byte-identical mirrored checkpoints. The Figure 1 highlighted L19/L39 pair would require exact C38/C78 ring matches, which this retained grid does not contain. Do not substitute C39/C80 and label them exact mirror counterparts.

Organization should retain Figure 1's **excess above background**, half-contrast width and absolute peak as three distinct observables. Absolute core amount is a different quantity and remains the denominator in the already recorded fractional core-rate support. These should not silently exchange definitions.

**Two distinct repair-evidence gaps must remain explicit.** Within the legacy inactive-withdrawal assay, Holmes lacks a retained equivalent linear measurement; do not infer its coefficient from symmetry and present that as measured. More importantly, the new common active-incumbent deactivation/recovery assay is not yet defined or measured here. Its new ring/linear baseline comparison is pending for every model; none of the legacy coefficients substitute for it. The mirror argument supplies a geometry expectation for an appropriately reflected perturbation, not a measured result for an unrun assay. This design launches no probe.

## 2. Input equivalence must be stated separately

Figure 1B uses the derivative at the opposite endpoint in WP/Goryachev: inactive concentration. The corresponding native Holmes derivative is inactive Rac divided by 7.5, although Holmes is not currently plotted in Figure 1B. The ring map uses the same native derivative averaged with the actual raised-cosine cue profile. For the antipodal baseline comparison, both can be reconstructed as **point readouts** from the retained fields. The existing ring patch-average differs from that point by at most 0.000877% in the matched WP sizes, 0.0000450% in Goryachev and 0.000000244% in Holmes; both definitions and their values are in the linked table. This numerical agreement follows from nearly uniform remote substrate and does not make the definitions identical.

The finite challenge protocols are **not mirror-equivalent**. A linear endpoint patch with physical support 3 reflects into a ring cue of full support 6; the retained ring cue has full support 3. The ring's 1000-on/13000-off responses must therefore remain a declared new spatial challenge. Basal organization, point gain and the whole-inactive-profile removal/return probe can be compared without equating finite-cue coverage, dose or reversal thresholds.

## 3. Gain maps now; the new common repair map depends on the finalized assay

Use the complete planned 17-size × 17-placement matrix in all three models: 867 rows, with 652 complete responses, 198 cue/core-overlap exclusions and 17 unavailable Holmes C80 cases. Keep the circumference and both realized arc lengths explicit. Within any fixed size all placements share the exact same complete native basal state.

**Initial gain map:** plot the existing cue-weighted native RHS derivative at cue onset. It is genuinely almost flat across eligible locations: the largest within-size relative range is 0.0392% in WP, 0.0891% in Goryachev and 0.00208% in Holmes. Use a common dimensionless color scale across all model columns so these variations stay visually negligible. One defensible shared reference is each model's own C30 antipodal gain, which has the exact L15 mirror match. A single 0–3 color range covers all retained values; WP/Holmes then remain close to 1 while Goryachev shows its substantial size effect. Raw native values remain linked; unlike a model-specific narrow color range, this does not magnify tiny changes into apparent comparable effects.

**New main repair baseline and map:** apply the exact forthcoming Figure 1C active-incumbent deactivation/recovery rule, with the same dose definition, spatial region, material bookkeeping, cue context, sham and observation window. Measure its basal response once per model/C; a basal quantity has no future cue-position argument. A distance-dependent map needs the same assay applied to the actual retained challenged states, preferably the prespecified early t10 state before most sites merge or vanish. Both the new native values and their common display scale remain pending; do not transplant the legacy K₁₀ range or label into main Figure 2C. The 50 exact qualified basals and all 652 complete conditions' t10/t1000/t2000 full native snapshots already exist as restart inputs. New short matched probe branches would be needed after the assay is settled; preparation and 14000-unit response histories need not be rerun. No jobs are launched by this design.

**Legacy support only:** the existing inactive-withdrawal basal coefficient K₀(C) is measured once per basal state, without distance dependence.

**Legacy conditional-repair diagnostic, not the new main C:** the retained assay uses the predeclared challenged snapshot at t=10, keep its cue on during the 0.1-unit paired probe, and read repair at t=10.1 after exact return. Define it explicitly as a challenged-state conditional repair coefficient K₁₀(C,d), not basal stability. Normalize to each model's own C30 basal coefficient if a common dimensionless 0–6 scale is wanted. The actual normalized ranges are WP 0.363–1.102, Goryachev 0.448–5.833 and Holmes 0.925–1.010. This preserves their different effect sizes. Alternatively report raw native coefficients with clearly common axes within each model; do not compare their absolute values as calibrated cross-model rates. A map of K₁₀/K₀(C) answers the separate question of change from that size's basal response and should be labelled as such.

For that legacy diagnostic, all 652 t10 primary coefficients pass the frozen numerical gates, and 644 snapshots retain separately resolved old- and cue-associated peaks. The remaining eight have no verified two-site identity; flag their probe as regional. Every t10 unperturbed fixed original core has a negative net material rate despite a positive repair coefficient. Diffusion is negative in all 652; reaction offsets some of that loss in 500 and is also negative in 152. This local open-region balance is not loss of all material from a moving site. Keep the absolute core-rate map or its concise signed-budget explanation alongside the conditional coefficient.

## 4. A third Holmes history can complete the fate illustration

The retained Holmes C40 matrix offers **no cue-site single-peak outcome**: d10–13 gives a spanning/merged region, and d14–20 gives two separated peaks. No existing fixed-C40 dose or duration alternative supplies a third fate. Do not suggest that the three fates were obtained merely by moving one cue on the same C40 state.

The clean retained third example is **Holmes C30,d12**, beside C40,d12 and C40,d16. It keeps the model, physical d12, cue width/peak/duration and mesh unchanged relative to C40,d12; changing circumference also changes total material, incumbent width and the complementary route (18 versus 28). The original and cue-associated maxima are both present at withdrawal and after 1000 cue-free units. By 2000 cue-free units there is one resolved maximum at 11.95 near cue12, and it remains there at the endpoint. This history supports loss of the original site with a cue-associated survivor rather than merely inferring replacement from a fixed-core average. A shared display through t4000 after onset shows all three outcomes; their final maps still refer to t14000.

The two C40 histories have identical complete basal Rac/Rho fields and isolate position within this protocol. The C30-to-C40 comparison is a size change with the stated coupled consequences. Use the h=0.05 matrix histories throughout this comparison; finer h=0.025 versions exist as support but must not be substituted into the statistical map as if they were the same exact states.

All eight need **no new integration**. Their 16 retained phase files occupy 183,263,398 logical bytes (201,957,376 allocated bytes), referenced in place rather than copied. A primary activity vector can use every recorded sample in all eight. Continuous inactive/Rho vector claims would need the corresponding retained field coverage and cannot be assumed for C80.

Cue times are phase-local 0–1000; recovery times are phase-local 0–13000 and must receive +1000 to combine histories. The C40 pilot stores 371 cue samples and 2771 recovery samples; C30/C80 store 371 and 261. Do not claim event times more precise than the source sampling. First-moment magnitude/direction must be interpreted with the full spatial histories because replacement, merger, rotation and cancellation can yield similar vector values.
