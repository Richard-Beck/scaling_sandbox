Certified takeover probability declines with size in each model at a common finite follow-up, but different certification fractions and pooled inputs limit population inference. Per-perimeter birth direction varies by model; it is not a universal consequence of enlargement. At native moment amplitude, eligible weak-input heading loss is allocated almost entirely to domain motion. As secondary domains appear, membership changes and the amplitude/shape/background remainder can grow; the pattern varies with model and size. This exact accounting remains descriptive, and the original unit-normalized point-region artefact is retained as a supplementary diagnostic.
