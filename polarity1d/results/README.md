# Retained polarity1d results

- `figures/`: all seven retained figures, PNG only.
- `data/`: compact figure source data, qualification metrics, and the accepted
  pixel-comparison checkpoint.
- `campaigns/`: fresh raw outputs for only the campaigns required to reproduce
  the retained figures. Scheduler logs are intentionally excluded.
