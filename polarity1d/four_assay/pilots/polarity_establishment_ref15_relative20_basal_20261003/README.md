# Chosen basis for reversal experiments

Decision recorded 2026-10-03: this corrected basal-withdrawal polarity-establishment
pilot is the chosen basis for moving on to reversal experiments.

## Why we assessed polarization

The purpose was to establish a defensible polarized starting state before applying
an opposite-end reversal cue, using a consistent spatial cue rule across models.
The protocol is independent rest -> finite localized cue -> withdrawal of the
added cue -> follow the released state under basal conditions.

For each model, length, amplitude and width, the duration scan identifies the
strongest observed stable cue-aligned endpoint and the shortest tested cue
duration within 1% of that endpoint's strength. It also measures the total time
to establish that polarity, its magnitude, and an approximate number of endpoints.
The endpoint count is a diagnostic, not an exact attractor census. This is a test
of persistent polarity after withdrawal, rather than sustained-cue following.

## Planned LEGI exclusion

We plan to exclude pure LEGI from the upcoming reversal experiments based on this
cue-free polarized preparation. Proper withdrawal restores its positive uniform
basal input, and LEGI then returns to a homogeneous response. It cannot provide
the persistent polarized starting state required by this protocol.

All 462 corrected LEGI combinations were unpolarized after withdrawal, with one
apparent endpoint and no qualifying establishment time. Setting total input to
zero in the preceding campaign froze its response after activator/inhibitor decay;
those apparent persistent endpoints do not justify including LEGI here. The
corrected pilot uses basal input 0.1, an explicitly recorded campaign convention.

LEGI remains in this pilot's results as evidence for the exclusion. A future LEGI
cue-following comparison would require a sustained initial cue followed by cue
reversal, which is a different preparation protocol.

## Basis for continuation

Proceed using this pilot for Wave-pinning, Otsuji, Goryachev, deBelly, Holmes 3
and Spring. Use qualifying persistent polarized endpoints and their saved full
native checkpoints to define starting states; unpolarized combinations are not
valid polarized preparations. A selected duration of zero means no polarizing
cue was needed and should retain that interpretation in subsequent comparisons.

Retain the standardized reference length 15 (Spring native reference 1), both
fixed-width conditions and the 20%-of-length condition. The reversal cue should
mirror the initial cue spatially, with the same amplitude and width for a given
condition, consistently across the retained models. This choice of pilot does
not establish a global optimum or finalize the length-response interpretation.

The completed pilot has 3,234 combinations and zero execution errors. Its final
checkpoint, arrival-time and endpoint-selection audits passed. The six non-LEGI
models' 2,772 summary rows exactly match the preceding campaign.
