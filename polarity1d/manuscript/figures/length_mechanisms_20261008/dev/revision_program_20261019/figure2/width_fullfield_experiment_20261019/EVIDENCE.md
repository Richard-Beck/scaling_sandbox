# Evidence and readout scope

The cue is the original right-end raised-cosine patch, with requested peak 0.1 (WP) or 6.4 (Goryachev), and unchanged stimulus × inactive activation transfer. Each pair starts from an identical copied, hash-checked corrected basal; support is physical in these fixed-length models even where inherited metadata says relative. The pulse is identical within each pair. It differs between size cohorts and is therefore not a controlled cross-size pulse comparison. Width changes integrated input as well as footprint.

Primary plotted reads are native active concentration maxima within the actual cue footprint and native active amount in the fixed initial incumbent region, divided by that region’s initial amount. The region is the connected component above the initial background-plus-half-range threshold containing the initial maximum. It is a fixed spatial ROI, not a tracked site identity or identified molecular damage. Full native active and inactive arrays are retained every 0.1 cue unit and 0.25 off unit through 10000. Plotting may subsample lines; metrics use every saved frame. First cue-on depletion crossings in the table are sampled threshold entries, not persistent state changes, optical latency calibrations or pulse-duration thresholds.

Original scalar orientation and retained-strength gates use the unchanged 2.5-unit grid over the final 500 off units. Native full-field tail stationarity is reported separately; neither scalar success nor one regional curve proves complete field replacement. The inherited N=201 grid is not a spatial convergence study.
