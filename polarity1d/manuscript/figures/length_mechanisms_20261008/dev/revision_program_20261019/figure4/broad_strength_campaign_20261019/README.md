# Broad-strength noisy-ring pilot: running

The author agreed to scale the entire existing positive noise signal. This
pilot asks how local organization changes across a common broad input-strength
axis, and whether the four models exhibit similar or different observed
sequences. It creates no new main-figure composition.

The nine common f values are **0.0001,0.0003,0.001,0.003,0.01,0.03,0.1,0.3,1**.
All four models retain their original three F4 sizes, exact basals, native
kinetics, noise correlations and model-specific time units. Mean and fluctuation
amplitude increase together. A smooth matched-mean control at each level helps
interpret the observed patterns; no fluctuation-only arm is included.
