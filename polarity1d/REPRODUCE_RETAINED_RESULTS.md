# Retained-result reproduction

This is the curated entry point for the seven retained PNG figures. All model
code, campaign inputs, execution scripts, and plotting scripts live inside
`polarity1d`; no data or code elsewhere in the repository is used.

Run `workflow/reproduce_retained_results.sh` from any location for the complete
HPC workflow. It leaves the rendering staging directories in place so a pixel
checkpoint can be performed before destructive cleanup.

## Layout

- `src/polarity1d/`: simulation and analysis library.
- `campaigns/`: immutable JSON inputs generated by the `create_*` scripts.
- `scripts/`: campaign creation, task execution, collection, analysis, and plotting.
- `workflow/`: SLURM launchers for the compute campaigns.
- `results/data/`: retained fresh source data and provenance.
- `results/figures/`: the single output directory for all retained PNGs.

The retained Figure 1 uses the compact `retained_phase1_tracking_v1` manifest
instead of rerunning unrelated Phase-1 assays. Representative Figure 1 configs
are selected from campaign manifests, so they never depend on prior result
directories.

The checkpoint procedure is: generate all campaign inputs, execute and collect
every task, run the dedicated analyses, rebuild the figures, compare SHA-256
decoded pixel arrays to the pre-cleanup PNGs, and delete the old result tree
only if all seven are identical or the user explicitly accepts each deviation.

## Curated scripts

- Campaign inputs: `scripts/create_retained_phase1_tracking_campaign.py`,
  `scripts/create_wp1_figure1_common_horizon_campaign.py`,
  `scripts/create_wp1_figure1_examples.py`,
  `scripts/create_wp1_tracking_reliability_audit.py`,
  `scripts/create_wp1_tracking_supplement_campaign.py`,
  `scripts/create_otsuji_reversal_geometry_sweep.py`,
  `scripts/create_debelly_standalone_figure2_julia_activation_defaults.py`, and
  `scripts/create_debelly_panel_a_10000.py`.
- Execution and collection: `scripts/run_phase1_campaign.py`,
  `scripts/collect_phase1_campaign.py`, `run.py`, and the corresponding
  `workflow/run_*` SLURM launchers.
- Analysis: `scripts/export_retained_phase1_tracking.py`,
  `scripts/analyze_wp1_tracking_reliability_audit.py`, and
  `scripts/analyze_otsuji_reversal_geometry_sweep.py`.
- Figures: `scripts/build_wp1_manuscript_figures.py`,
  `scripts/build_debelly_standalone_figure2_v2.py`,
  `scripts/build_debelly_figure2_kymograph_supplement.py`, and
  `scripts/qualify_models.py`.
- Final assembly: `scripts/package_retained_results.py`.

The general campaign runner and simulator are shared within `polarity1d`; none
of these scripts reads code or data from another repository module.
