# Analytical Gaussian hierarchy

Five studies: Xuan2018, Mallin2023, Jemaa2017, Jemaa2023, and regular Hosny hypoxic N/P baseline. All Hosny KD and HIF/RhoA controls are excluded.

Each study has a reference persistence time and physical velocity-noise strength, and a WGD fold change in each. Log baselines and log fold changes have separate shared centers (profiled means). Fixed baseline/effect log standard deviations are log(10)/log(2), with half/double sensitivity runs. These are descriptive regularization scales, not estimated biological variability. Hosny has two unpooled signed drift velocities, equivalent to baseline plus additive WGD effect. Both groups' persistence times are bounded in (1e-6,12) hours, with either direction allowed.

`fit.py` optimizes only analytical predictions with bounded SciPy trust-region least squares, eight starts per pooling choice. Mallin directness uses mean endpoint divided by mean path. Hosny uses only three medians per group: mean path as median path; Rice endpoint median divided by mean path as median directness; signed mean displacement divided by mean path as median parallel migration. The objective has 18 data residuals and 20 pooling residuals. Scraped tolerances/IQRs set data scales, not claimed standard errors. Hosny nonmedian path predictions are undefined under this approximation and are not scored.

`validate.py` selects the minimum analytical objective separately for each pooling choice, freezes parameters, and checks them with 16,384 exact integrated Gaussian OU tracks per condition for each of two independent scrambled Sobol ensembles. Both observed quartiles and additional held-out observations are checked. No validation result changes parameters or triggers optimization. It also saves 32 example tracks per study/condition. Units are hours and micrometers; noise strength is micrometers/hour^(3/2). Sampling cadences/durations follow prior campaign assumptions, not newly recovered experimental metadata.

Results are in `results/report.html`, with full JSON objectives, source hashes, validation comparisons and NPZ tracks alongside. Report is regenerated by the validation producer and records generation time; no browser auto-refresh.

Run from repository root:

```
sbatch --array=0-23 wgd_langevin/gaussian_hierarchy/run.slurm
sbatch --dependency=afterok:JOBID wgd_langevin/gaussian_hierarchy/validate.slurm
```
